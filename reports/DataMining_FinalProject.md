# DATA MINING COURSE FINAL PROJECT BRIEF

## Domain-Specific Data Mining & Dashboard Development

| Item | Details |
|---|---|
| Discussion | Two-Phase Project |
| Team Size | 2 Students |
| Tools | Python · Git/GitHub |
| Output | Dashboard + Notebook + Presentation |

---

# 1. Project Overview

This project challenges students to conduct a complete, end-to-end data mining study inside a domain of their choice, following the industry-standard CRISP-DM methodology.

The emphasis is not only on producing correct models but also on demonstrating professional skills:
- Clean version-controlled code
- Reproducible experiments
- Insightful visualizations
- Interactive dashboards
- Portfolio-quality project delivery

---

# 2. Domain & Dataset Selection

Students may choose any domain and dataset that interests their team.

Suggested domains include:
- Retail
- Healthcare
- Finance
- Social Media

Teams may also propose their own domain and dataset with proper justification during Phase 1.

# 4. Technical Requirements

## 4.1 Required Mining Techniques

### Clustering
- K-Means
- DBSCAN
- Hierarchical Clustering
- Gaussian Mixture Models

### Regression Models
- Linear Regression
- Ridge/Lasso
- Polynomial Regression

### Anomaly Detection OR Text Mining
- PCA
- One-Class SVM
- TF-IDF
- LDA Topic Modelling
- Sentiment Analysis

### Classification
- Decision Trees
- Random Forest
- Logistic Regression
- Rule Induction

---

## 4.2 CRISP-DM Compliance

| Phase | Description |
|---|---|
| Business Understanding | Define objectives and business goals |
| Data Understanding | Explore data distributions and issues |
| Data Preparation | Clean and engineer features |
| Modelling | Train and compare models |
| Evaluation | Assess metrics and objectives |
| Deployment | Dashboard as deployment layer |

---

## 4.3 Dashboard Requirements

The dashboard must:
- Be built using Streamlit, Plotly Dash, or Power BI
- Include one section per mining technique
- Include at least one global filter
- Include a Business Insights panel
- Include screenshots in final presentation

Cloud hosting is optional but considered a bonus.

---

## 4.4 Git & GitHub Requirements

Repository must include:
- Public GitHub repository
- Clear repository name
- README.md
- requirements.txt or environment.yml

# Important Note

The goal is not perfect model accuracy.

The real objective is demonstrating the ability to:
- Define problems clearly
- Apply appropriate techniques
- Interpret results
- Communicate findings professionally
- Deliver reproducible and well-documented work
